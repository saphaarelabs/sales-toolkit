

# CloserKit — Free, Open-Source Sales Tools

## Overview
CloserKit is a clean, minimal, 100% client-side toolkit for salespeople. No accounts, no data collection — everything runs in the browser. Think "ILovePDF but for sales." The goal: help reps close more deals faster.

---

## Homepage
A clean landing page with:
- Bold headline: "Free Sales Tools to Close More Deals"
- Subtitle emphasizing open-source and privacy (no data stored)
- Grid of tool cards showing all 8 tools with icons, names, and one-line descriptions
- Category filters (Calculators, Email & Outreach, Prospecting, Docs)
- Simple footer with GitHub link

## Tool Pages (shared layout)
Each tool gets its own page with:
- Clean form/input area on the left or top
- Live preview/output on the right or bottom
- Copy-to-clipboard and export options where relevant
- "Back to all tools" navigation

---

## 8 Launch Tools

### 1. Commission Calculator
Input deal size, commission rate, and tiers. Instantly see earnings breakdown. Support for multi-tier structures (e.g., 5% on first $50K, 8% above).

### 2. ROI Calculator
Input customer's current costs, projected savings, and implementation cost. Generates a clean ROI summary with payback period — copyable for proposals.

### 3. Cold Email Generator
Pick a scenario (intro, breakup, referral ask, etc.), fill in prospect details, and get 2-3 email variations with personalization placeholders. Copy with one click.

### 4. Follow-up Sequence Builder
Build a multi-step email sequence with suggested timing (Day 1, Day 3, Day 7, etc.). Each step has editable templates. Export the full sequence.

### 5. ICP Builder (Ideal Customer Profile)
Guided form: industry, company size, budget range, pain points, decision-maker titles. Generates a formatted ICP document you can copy or download.

### 6. Objection Handler Script Builder
Browse common sales objections (price too high, not the right time, using a competitor, etc.). Each has suggested response frameworks. Users can customize and save to clipboard.

### 7. Email Signature Generator
Input name, title, company, phone, social links. Live preview of a professional HTML email signature. Copy the HTML to paste into any email client.

### 8. Discount Calculator
Input deal value, proposed discount %, and margin. Shows impact on revenue and whether the discount is sustainable. Helps reps negotiate without giving away the farm.
